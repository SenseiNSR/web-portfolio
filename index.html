GESTURE-AID

Sign Language Recognition

A real-time AI sign language translator that bridges the communication gap. It uses 3D hand tracking and temporal neural networks to translate dynamic gestures into text and speech instantly.

Python PyTorch OpenCV MediaPipe
View Project Details ↓

An AI-powered assistive communication system designed to bridge the gap between hearing/speech-impaired individuals and those who do not understand sign language. It captures a live webcam feed, tracks hand movements in 3D space, and translates dynamic sign language gestures into readable text and synthesized speech in real time. Instead of just recognizing static hand poses, the system continuously monitors the temporal flow of gestures using a rolling window of frames.

Key Features

  • • Real-time translation
  • • 3D Hand Tracking
  • • Temporal Gesture Flow
  • • Jitter Debouncing
  • • Offline Speech Synthesis
